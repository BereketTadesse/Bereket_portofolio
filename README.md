# Bereket Tadesse — Personal Portfolio

The personal portfolio website of **Bereket Tadesse** (Backend Developer), showcasing backend architectures, REST APIs, projects, skills, and experience.

## Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Animations**: Framer Motion
- **Routing**: React Router

## Quick Start

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
